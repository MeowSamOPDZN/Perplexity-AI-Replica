# Perplexity AI Replica

A full, pixel-faithful **frontstack replica of [perplexity.ai](https://www.perplexity.ai)** — built from a live audit of the real site (Oct 2026, logged-out state) with **every button, dropdown, menu and modal working**.

**Live demo:** https://perplexity-replica.vercel.app/

![stack](https://img.shields.io/badge/stack-vanilla%20HTML%20%2B%20CSS%20%2B%20JS-20808d) ![type](https://img.shields.io/badge/type-AI%20chatbot%20replica-111) ![license](https://img.shields.io/badge/license-MIT-lightgrey)

## What's inside

- **Sidebar (240px, collapsible to a 56px rail)** — New, Computer, Automations, Artifacts, Customize, Projects, Recents, View plans, Sign In
- **Hero + composer** — serif "What do you want to know?", rotating placeholders (`Ask anything…` / `Type / for search modes` / `Type @ for connectors`)
- **Working composer menus** — Add files/tools (+), Search-mode dropdown (Search, Deep research, Model council, Learn step by step), model picker with 11 models (GPT-6.1 Sol, Claude Sonnet 5.5, Gemini 4 Argon, Kimi K3, Grok 4.7…), Computer toggle, dictation, voice mode
- **Answer pages** — source cards, inline citation chips, per-section copy tools, follow-up questions, "Ask follow-up" composer, simulated search with skeleton loading
- **Discover feed** — Top/Topics tabs, lead story + card rows + wide stories, Like/Dislike, right rail with "Make it yours", live weather widget (°F/°C), Market Outlook sparklines, Trending Companies
- **Computer** — delegate sessions that run and complete; **Automations** — templates + create-your-own with schedules; **Artifacts** — filters, grid/list, create; **Customize** — connectors & skills with search and categories
- **Plans dialog** — Free / Pro ($17) / Max ($167) with Personal/Education/Business switcher
- **Login modal** (Google / Apple / email / SSO) with a local demo sign-in that actually unlocks features, **incognito mode** (Ctrl+;), **command palette** (Ctrl+K), cookie banner — all state persists in `localStorage`

## Real AI

Answers are **real**: the composer talks to `api/chat.js`, a Vercel serverless proxy that calls **Mistral Large** (`mistralai/mistral-large-4-0`) and streams the reply token-by-token into the Perplexity-style answer page. Follow-ups keep full conversation context. The API key lives only in the `XKIRO_API_KEY` Vercel env var — never in code.

The model switcher contains exactly one model — **Mistral Large**, with the real Mistral logo.

## Tech

Organized static front-end — no build step, zero dependencies:

```
index.html        markup + SVG icon sprite
css/main.css      desktop styles
css/phone.css     phone styles (Perplexity-app layout: top app bar, bottom tab bar, bottom sheets)
js/core.js        state, menus, modals, composer
js/ai.js          markdown renderer + streaming client
js/app.js         views, Discover, pages, init
api/chat.js       Vercel serverless AI proxy (key from env)
```

Fonts: Inter + Newsreader via Google Fonts. Full build spec in [`SPEC.md`](./SPEC.md).

## Run locally

Open `index.html` in any browser, or:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```
